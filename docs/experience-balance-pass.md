# 体验与数值优化记录 — 2026-10-01

## 本轮已经实现

- 右键蓝图和场上塔调级只允许开发测试模式，运行时入口与输入入口均有检查。
- 正式波次 Boss 赏金即时结算一次，不再生成可重复领取的水晶；测试沙盒保留掉落拾取。
- 水晶半径使用平方根缩放，上限 12；零价值碎片不生成掉落。
- 开局资金 45，可以选择多座速射塔或榴弹炮。塔本身价格与伤害暂未调整。
- 前六波改为基础、疾袭、重装、护盾、召唤、治疗逐步引入；保留 34 波循环。
- 解锁奖励附带该塔当前造价的试建资金；蓝图升级附带一次价格差额补贴，文案说明只影响后续建造。
- 奖励权重参考场上塔的使用数量，同时保留近期出现惩罚，避免一直强化同一种塔。
- 奖励以运行时余额计算，避免读取 Boss 结算前的 HUD 余额。
- 暂停按钮与 Esc 切换；失焦与切后台自动暂停、清除输入；恢复需要玩家主动操作。帧间隔上限 50ms。
- 暂停和奖励选择不计入战斗时间；窄屏 HUD 调整，失败显示到达波次。
- 正式阶级 Boss 正确使用已编写的技能和应对资料；双子阶级保持双实体与阶段数量。
- Boss 应对提示常驻血条，中文显示；阶段介绍期间停止启动技能，首次技能错开 0.65 秒。

## 数值假设与验证限制

45 初始资金、解锁试建补贴和教学波次属于第一版调参，并非已证明的最终平衡。取消双倍 Boss 收入会降低长期收入，补贴与教学难度需要一起观察。恢复正式 Boss 技能也会提高部分遭遇的压力。

自动化覆盖赏金只付一次、高价值拾取、阶级技能、双子构造、教学波次和补贴结算。浏览器检查覆盖开局、正常模式右键、暂停恢复、窄屏布局。未完成 34 波通关或真实手机触摸测试。

## 后续验证顺序

1. 采集每波战斗时间、玩家受伤来源、每塔有效伤害/存活时间/损毁、资源拾取率和奖励选择率。先做本地局内统计，不发送到外部服务。
2. 固定随机种子，以相同阵型测试速射堆塔、范围清场、控制搭配与长程配置。比较实际输出，随后调整塔价格与伤害。
3. 优先评估第 6→7、18→19 波的压力与收入变化，增加章节完成反馈。
4. 设计角色或阵地联动强化，避免只增加线性属性；同时评估修复、重部署等经济消耗。
5. 出生距离与宽高比、连续弹道碰撞、实际触摸手势仍需要独立实现与验证。

## Boss 设计建议

### 每个 Boss 围绕一个能学会的动作

| Boss | 核心应对 | 下一步机制优化 |
| --- | --- | --- |
| 司令 | 清理护卫后集中输出 | 护卫完整时提供可见保护；护卫被清掉后短暂暴露弱点 |
| 猎手 | 横向躲冲刺 | 预警锁定方向后不再追踪；冲刺结束进入明显恢复期 |
| 堡垒 | 配置持续火力并保留阵地 | 装甲与核心开放交替，给集中火力一个明确收益窗口 |
| 棱镜 | 找安全角度 | 先演示单线，再组合交叉线；锁定后保留足够撤离时间 |
| 蜂巢 | 在打 Boss 与清增援之间取舍 | 将巢点做成可破坏实体；清巢确实减少下一轮召唤 |
| 冰环 | 分散关键塔并移动 | 冻结目标先显示标记；避免冻结与范围攻击一起瞬发 |
| 磁轨 | 打破塔的直线排列 | 贯穿攻击锁定后固定方向，让玩家有机会牺牲一座塔保护主阵地 |
| 收藏家 | 追讨被偷资源 | 把被偷资金绑定到可击破搬运单位，击破可以追回 |
| 双子 | 选择击杀顺序 | 两者提供不同压力，击杀一位解除对应机制并强化另一位 |

巢点、可破坏墙、资源搬运与真正的弱点窗口是设计提案。当前部分名称只是区域/线段伤害表现，并没有这些实体交互。

### 阶段要改变决策与节奏

第一阶段单独展示招牌动作，第二阶段用辅助机制改变站位，第三阶段以更短节奏重复已学会的组合。避免纯粹叠加独立技能冷却，造成多个预警同时覆盖所有出口。

建议采用“预警 → 锁定 → 执行 → 恢复”的攻击状态机，区分主攻击和辅助动作。正常阶段同时最多一个主攻击；第三阶段才允许经过验证的组合攻击。恢复期应该停止追赶或暂时开放弱点，让自动射击也能兑现玩家躲避成功后的收益。

初版调参目标：预警约 0.8–1.2 秒，恢复约 1–2 秒，Boss 战约 30–60 秒。这些只是实验目标，要由玩家移动速度、危险区距离、常见阵型输出和实际游玩数据决定。

验收时检查每个预警是否存在可达安全位置、技能是否造成不可避免的连续伤害、核心阵地被摧毁后是否还有恢复机会，以及玩家是否能说明自己为何受伤。
