# R13 same-source-scale preflight

The two same-source-scale.jpg files use one source pixel per output pixel for all poses, with a shared sole baseline and horizontal two-foot midpoint. They do not fit each pose independently. Root measurement JSON lists selected two-foot runs. This is source inspection, not actual module approval.

Axis landmarks are manual approximate measurements in the generated atlas, not an assumption of 45 degrees. Some sources are closer to 30–40 degrees. The measurements reveal small pose-to-pose tube/beak differences; no claim of exact rigid compliance has been made. The same-world registered runtime will use a uniform identity scale and disclose those differences. Any corrective shared rigid layer must retain true source pixels and preserve connected outer contours, rather than painting a seam.

Attack uses corresponding neutral derivative, explicitly not a supplied independent attack pose. No diagonal candidate is yet used by production. Existing approved cardinal frames remain until new runtime approval.
