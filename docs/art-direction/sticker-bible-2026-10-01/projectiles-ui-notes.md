# 弹体、危险区域与 UI 检查

弹体板覆盖 PLAYER 与全部9塔，半径标注是配置 radius，不是直径。刻意简化玩家弹体为蜂蜜种子，避免把玩家身体当弹体；BURST 需要四弹，图中初稿三弹错误经局部重绘修订，按最终版本参考。

危险板覆盖通用线/圆/墙体语法与8种交互反馈。55个现有标签共用原画语法，完整分组在 README；同名标签有不同几何形状时，实际运行时参数优先。尾迹、冲击花瓣和视觉闪光不能扩大碰撞范围。圆形冻结/毒区的示意不是新增技能。

UI三板分别覆盖主HUD、流程与开发工具。HUD修订以九塔设定板为额外身份参考，改善初稿混同的RAPID/RAIL/BURST/SENTINEL卡片；主流程修订去除不存在的树木地形，将资金与修复示例分开。开发工具修订使用实际敌ID、同一司令的阶段缩略图，并为测试导出提供备注输入、JSON预览和现有操作。

HUD局部重绘后，SNIPER小图仍有近似双喙的细线，不能直接作为最终塔图标；制作时必须取 towers-01 的单喙身份，RAIL取 towers-03 的双喙身份。FROST已经修正为单水平嘴。角色设定板优先于UI场景中的简化缩略图；这处残留不影响所有单位的完整主设定覆盖。

图示文案与参数不作为新规格：原画生成可能产生局部数字或汉字偏差，正式制作从配置和组件读取；菜单只保留升级/降级，图中费用与升级效果是布局占位。音频设置的位置、结束统计、提示关闭、手机操纵轮廓是界面布局提案。所有图像保留源稿、修订稿和完整提示。

保留可用性规则：友方弹核心与敌方危险标识分离；虚线预警与连续生效边界分离；可放置/无效同时用勾叉；信息区不接收移动操作；建造卡横向滚动与拖动手势分离；触控目标建议44px以上。原画没有进行实际手机或高密度实战验证。

少量色块明暗与椭圆软影仍属于概念呈现，正式矢量素材应去掉这些非必要细节。交付为设定稿，不是生产SVG、透明精灵或UI代码。
