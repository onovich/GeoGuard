# 逐身份轮廓与部件构造

以下是逐张view_image查看最终身体板后形成的制作准备。轮廓节点顺序、遮挡及部件拓扑是明确的构造方案；源画布像素、关节位置与碰撞映射仍须在获准的新rig文件中制作/测量，未把板页坐标或旧提案[256,416]当生产锚值。这里只规划本组身体，不扩大总项目计划。

## 共同生产边界

源稿采用可编辑三次贝塞尔闭合轮廓，器官使用有语义id的独立形状及连接点；五官属于body局部坐标。连体瓣可以是同一路径的多个可编辑弧段，不把每瓣画成互相浮动的圆。接缝处只保留原图必要的分界弧线，避免重叠描边造成硬机械铰链。圆角、奶油高光与暖深棕描边沿当前PALETTE观察值brown #4B281C、coral #F77965、cream #FFF9EF准备；颜色/线宽最终随分组合同和样板，不从联合图采像素色码。敌人红珊瑚为主，脸窗/眼槽深棕，必要奶油负形，克制阴影。

身体不含地面阴影、root十字、基线、标签、弹体、血条、护盾圈、治疗/干扰光环、出土波纹、召唤实体或分裂实体。所有本组muzzles为空，不新增炮组。整体脚根或投影R不随动作变动；逻辑C与radius只读，R/C固定中性偏移；不以每帧bounds重新居中。脚关节与接地点分开：脚可局部屈曲，固定地面接触仍守R，不能把整条腿冻结后让身躯滑离腿根。

已读rigData.js与rig.js：支持独立Bezier shapes、softPivot、fixed shapes、joints、partTransforms及poseVariants。观察到当前统一sampleSoftPose形变；不能据此声称本组专属动作已可实现。分组合同需允许身份专属关键轮廓/姿态变体；SPLINTER局部抬升、SCOUT腿屈曲及SIEGE拳臂抬起不能仅靠通用sx/sy替代。此包仅记录需求，不改共享sampler。

## FAST — 板01第一行

锁：前倾圆身，2长后倾耳、2后足、1侧软瓣，2眼、1短椭圆口。

轮廓从右侧短圆鼻额开始，向下以短弧包住前脸，腹部宽长弧落到双足之上，再收回左后臀；背线升向耳根。两耳是向左后扫的长扁带：远耳在上、近耳更水平，耳尖均钝圆，根部之间有明确奶油楔形空隙。不能替成两根竖芽或兔子正面圆头。耳根与背部连续，侧瓣是一枚左后圆软团，不是第三脚。

层序：后足 → 远耳 → 主身/近耳连接 → 侧瓣及连接短弧 → 前足 → 两枚竖椭圆眼 → 短椭圆口。眼口集中在右前脸，面部整体随身躯；耳/瓣关节跟随body。SQUASH后腹加宽、耳带贴低；STRETCH身/耳上弧升高；RUN/ATTACK同第4格，前足屈入腹、后足后蹬且身前倾。脚数仍2，耳数仍2；root留在地面中心。

## TANK — 板01第二行

锁：宽圆团，3上肉瓣、2大拳臂、2脚，1横眉槽、1口、1方牙。

主体为宽花冠式一体块：左上瓣 → 高中央瓣 → 右上瓣，三峰之间浅凹，随后以短肩瓣过渡到宽腹底；不能用椭圆加三枚悬浮芽。左右拳臂远大于脚，外缘圆鼓，内缘用单短弧表达握拳折线。中央横眉槽为厚弯月，奶油方牙在其下的口锚；保持原图连读的单个面部结构，不另添两只眼或第二张嘴。

层序：两脚 → 主身三瓣 → 两拳臂/接缝 → 眉口深色结构 → 方牙。SQUASH整冠压低、横向宽，拳更贴地；STRETCH中央瓣增高而两拳仍连接原肩；HEAVY_MOVE明确复用SQUASH；ATTACK用第4格，拳略上举、下腹局部收紧。与SIEGE区分在三瓣冠/单方牙，不复用额板轮廓。

## SPLINTER — 板02第二行

锁：单滴形、1眼，0手脚口。

一条闭合轮廓从略偏右的钝尖顶出发，右侧先轻微内收再鼓起下腹，底部大圆弧，左侧斜弧回尖顶。尖顶有弯钩方向，不是轴对称水滴。单眼位于右侧偏中下，深棕椭圆含1奶油亮点；亮点属于同一眼器官。

层序：连体滴形 → 单眼 → 亮点。SQUASH滴尖倾斜、下腹变扁宽，STRETCH尖腹拉高。源HOP/ATTACK第4格画了悬起身体；主审实施预检随后明确不允许整滴额外上移，故r02采用接地不变的竖向拉伸/翘尖表达跳跃意向，源悬起格只保留历史来源说明，不按其高度烘焙位移。不能加脚弥补锚点。关系板确认SHARD移除后请求3个独立SPLINTER，每个独立uid/root；本组不实现SHARD，不把三滴组成一个rig。

## SHIELD — 板03第一行

锁：圆主体、1大盾瓣遮近侧脸、1后拳、2脚、1眼亮点保留脸锚。

主身是左侧可见的高圆团；右前大盾瓣为倾斜长叶盾形，尖顶圆化，右弧外鼓，下端钝尖触近地面，左边长弧从额前一直遮到下腹。盾是软器官而非持握独立道具。左后拳仅1枚，带短连接弧。近侧脸只保留被盾遮住一部分的深棕眼区及奶油亮点；不能添加第二眼/嘴。

层序：两脚 → 圆身 → 后拳 → 单眼锚 → 盾瓣前遮挡。盾与身体挂点随软形变，形状长轴/覆盖比例守住；盾尖不穿脚。SQUASH盾变短宽、低贴，STRETCH盾升长，GUARD/ATTACK第4格盾前倾、后脚向后伸。身体中不画护盾圈。板标签附近弱引线不是root；固定锚取基线上薄荷十字的语义，不提取标签线。

## MEDIC — 板03第二行

锁：4圆瓣主体、2卷臂、2脚、中央1奶油十字，0眼口。

主体轮廓为上下两对圆瓣：顶部中心凹口 → 右上瓣 → 右腰收口 → 右下瓣 → 底中心凹口 → 左下瓣 → 左腰 → 左上瓣，连成四叶结构。两侧卷臂各一枚圆卷，内卷以一条C弧表示，不作为额外手指。奶油十字四端圆润，在中央固定局部锚，须与4主体瓣有足够负形区分。

层序：两脚 → 四瓣连体 → 两卷臂 → 奶油十字及深棕边。SQUASH压低上下瓣/横扩双卷，STRETCH提高上瓣并保留中心凹口，HEAL/ATTACK第4格两卷略张、仍是同4瓣同十字。十字不是脸，不增眼口；治疗光环独立。

## BOMBER — 板04第一行

锁：圆主体、1弯引信芽、2鼓腮臂、2脚，2眉眼槽、1口、1舌。

圆主体上方的小颈自然接一条向右弯的钩形引信芽，芽末钝圆，无火花。脸左右有鼓腮臂，两枚内缘括弧表示腮臂连接，不画成断开的拳球。两眉眼槽向中央下斜，口为小深棕开口，内含源图可见的奶油心状舌形；它是1舌，不改为方牙。

层序：双脚 → 圆身与引信 → 双腮臂 → 两眉眼槽 → 口 → 舌。SQUASH压身但钩芽连续；STRETCH颈身提高；INFLATE/ATTACK以第4格宽鼓腹/鼓腮为专属变体，不直接沿旧anatomy动作板的STRETCH定位替换。爆炸和引信火花不进body，不靠姿态生成爆炸伤害。

## JAMMER — 板04第二行

锁：低圆主体、2长下垂天线耳、4短基底瓣、2眼槽、1折嘴。

主体低拱，上缘两天线从左右头顶根生出，先上拱再外下垂，耳端宽钝。双耳之间保留奶油通孔状空隙，不能变成头上两短芽。底缘左右各2瓣，共4短瓣；外瓣较侧向、内瓣更向下，不能简化为两只普通脚。两U眼槽在原位闭合，中央折嘴是连续W式折线。

层序：后侧基底瓣 → 主身/双天线连接 → 前侧基底瓣及必要接缝 → 两眼槽/折嘴。SQUASH耳弧压低且横长；STRETCH耳拱与身高升起，4瓣仍短；JAM/ATTACK第4格耳向外张、低身维持。不画干扰圈/电线，局部耳摆根部不脱离。

## PHASE — 板05第一行

锁：1连体弯滴幽灵尾、尾末2尖瓣，1长黑脸窗、2白眼，0肢体。

轮廓是左上大圆头，左外弧下行到弯腹，腹底向右回卷；右尾有两枚尖瓣及其间明显负形凹口，随后上缘长弧回到头右侧。尾尖仅为连体路径的两个端瓣，不拆成两条独立尾或腿。脸窗长水滴，从头内上方沿下弯收尖，2短奶油眼位于窗上端；无口。

层序：连续头腹双尖尾 → 脸窗 → 双眼。SQUASH横卧/压低，STRETCH高竖长，PHASE_DASH第4格保持完整身体拓扑；透明状态只改变完整body alpha或独立状态层，不缺失尾/眼。实际是phased定时切换与普通追踪，图册名不授权dash/瞬移/拖影新实体。

## BURROWER — 板05第二行

锁：低半圆主体、2三指掘爪、2底脚、2眼、1大圆鼻口。

主体宽低半拱，肩部左右短起伏接两爪；每爪外边闭合并清楚分3枚圆指端，内部只有2条指缝。爪根宽短贴肩，不能变成三枚独立手指球或一枚拳。两暗底脚从腹下露出；两斜眼在大圆鼻口两侧，鼻口是单个圆深棕器官，不再新增嘴。

层序：暗双底脚 → 半圆身 → 左右三指爪 → 两眼 → 圆鼻口。SQUASH半拱低宽、三指仍可数；STRETCH只提高拱顶；EMERGE第4格复用完整显现身，不复制另一只地下身。出土波纹/土块独立；显现不重定位逻辑C。

## BEACON — r01身体板第一行

锁：1钟形瓶身、2顶触芽、2脚、1大黑口+1舌，0眼。

顶部颈线连左右细短触芽，每芽末圆球，与身体连续；侧壁上段较窄向下渐张，底裙左右外翻为宽圆唇，腹底中央浅凹。大口是纵向深棕椭圆占身中央，底部1珊瑚心形舌；不添加眼，也不把嘴改成远程炮孔。

层序：双脚 → 瓶钟身/双触芽 → 大口 → 舌。四格分别NEUTRAL/WINDUP/TRIGGER/RECOVER；SQUASH是WINDUP，STRETCH是TRIGGER，MOVE明确N→W→T→N。召唤状态使用W→T→R身体子姿态，R与N近似但独立记录。身体不含板下方三个BASIC。请求3个、实际spawnAround可减至0，数量/出生坐标/uid/HP全由逻辑；不能将3个从嘴中吐出。

## SCOUT — 板06第二行（注意不是第一行）

锁：1头罩单眼球、2长软腿、1大眼睑1眼，0嘴手。

头罩圆弧左高右低，下缘是一条斜盖在单大眼球上的眼睑。奶油眼白仅1区，深棕瞳仅1个；罩与眼球须共父级锚并维持遮挡，不加第二眼。两长软腿从头罩下部不同挂点向地面延伸，脚端圆膨。腿部负形是身份核心，不能短腿花团化。

层序：两腿（各从髋到圆脚连续Bezier）→ 奶油眼球/瞳 → 头罩/眼睑前遮挡。SQUASH头降且两腿向外弯，STRETCH腿拉长、头升，CHASE_PLAYER第4格头前倾/腿外开、眼睑更水平。脚接地固定，腿上端须跟随头，不允许固定整腿与缩放头分离；需要关节屈曲或poseVariants。

## SIEGE — 板06第一行

锁：低宽主体、1大额板、2拳臂、2脚，额板下2眼、1嘴。

宽低身两侧肩弧接硕大双拳；中央额板为圆顶倒盾形，上宽下收钝端，覆盖面部上半。两眼在同一深棕眉下窗中仍各保留1奶油眼区，左右两锚；底部1小椭圆口。额板与TANK三冠形完全不同，不添加方牙。

层序：双暗脚 → 宽身 → 双拳/连接短弧 → 双眼/口 → 额板前遮挡。SQUASH板/身低宽，STRETCH额板向上延长但仍遮眼上部。STRIKE_TOWER第4格抬起画面右拳：从右肩同根伸出软臂连接到上举拳，另一拳仍原处；不能将拳移走留断臂、不能新增第三拳。以专属形状变体准备，靶塔/命中冲击独立，不改变攻击目标或结算。
