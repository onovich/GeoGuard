# r05 · 桌面 1.25 倍世界镜头最终接入候选

主审已选择桌面世界镜头 1.25 倍。本包实现该选择，并修复双子遭遇拖动预览错误身份、重置后的建造栏取消区域。**integration 所有权源码封存后冻结，等待 UI 和最终 QA；本包不是完整项目验收。**

入口：[证据浏览页](evidence.html)、[同世界回放报告](browser-final/report.json)、[密集场景与双子报告](scenes-02/report.json)、[构建及回归](validation.json)。最终代码快照为 `source-final/`，源文件清单为 `captured-source-final.json`。角色依赖为主审通过的 characters r04：`29b0c819836463d6712e26b13947953ad50b61b49347d97c0a1ff75d7ef542c3`。

## 实现与逻辑边界

- 新增 `worldCamera.js` 作为纯表现层变换：窗口宽度 ≥768 时 1.25 倍，移动端原尺度不变。矢量角色、地面、危险区、血条、飘字、ghost、射程圈统一变换；DOM HUD 和建造栏尺寸不变。传统 fallback renderer 使用同一相机，但默认资源路径必须零 fallback。
- 点击/右键与拖建共用包含原震动偏移的逆变换。冻结的 placement engine 接收 hook 适配后的等价 1 倍坐标，继续执行原碰撞、价格、间距规则；pointerX/Y 和取消区域保留真实 CSS 坐标。拖动时相机继续移动，ghost 每次绘制前重新对齐指针，释放时重新计算位置。
- 原自动索敌没有鼠标瞄准逻辑。鼠标拖动控制屏幕空间摇杆，保持原 50px 位移和运动方向/速度。右键塔菜单在视口边缘进行屏幕位置约束。
- 原波次出生半径依赖窗口尺寸；继续传入原窗口尺寸，绝不除以 zoom。相机跟随、碰撞半径、AI、技能、波次、世界出生位置保持原逻辑。所有 `src/data/**`、`src/logic/engine/**` 与 r04 快照逐文件哈希相同。
- `TWINS` 是遭遇模板，不是身体资源。预览使用已注册 `boss:TWINS_SUN`，实际放下后的两个原引擎实体仍分别映射 `boss:TWINS_SUN`、`boss:TWINS_MOON`；不再请求虚构的 `boss:TWINS`。
- 回放发现：重复 init/reset 保留已挂载 BuildBar 时，runtime 清空其旧矩形，而 React 无需重新挂载。现由 hook 在拖建提交时读取真实建造栏矩形，避免把拖回 UI 的释放误判为建造。引擎文件未修改。

## 验证结果

**12 个浏览器用例、6 对同世界回放全部通过**：1440×900、1280×720、960×720 × DPR 1/2 × zoom 1/1.25。原 `initGame`、DEV 原时钟桥、真实鼠标键盘；没有虚构状态注入。

正常模式以资金 45 开始，经两次真实 BASIC 拖建剩余 15，再推进原引擎 600 帧，验证原波次出生。战斗回放使用真实 Debug GUI 创建塔与重装兵、键盘移动、相机移动中拖建及原攻击事件。两档的世界状态、战斗事件、随机数调用次数一致。只从比较对象移除 CSS pointer/摇杆起点/拖动指针坐标；保留摇杆方向、所有世界字段和事件，数值按 1e-9 取整以消除逆变换浮点尾差。浏览器 MouseEvent 使用整数 CSS 坐标，测试选用两档均能精确表达的同世界点，避免把坐标取整当成玩法差异。

实际 Canvas 射程圈 CTM 验证包含 DPR×zoom，投影中心与真实指针相差小于 0.001 CSSpx；此容差考虑 Canvas 浮点矩阵。另覆盖右下角实际建塔/右键升级、菜单不出界、重置后拖回建造栏取消、暂停与恢复、干净重置、摇杆移动、正确 DPR 画布尺寸。

**6 个补充场景用例通过**：三尺寸 × DPR 1/2，双子 ghost 与实际双身体、原 GUI Balanced 预设和 26 个普通敌人及两个 Boss、真实危险区、真实 Phase 3 震动下的 ghost 逆变换。1440×900 DPR1 还逐个拖动原 Boss 列表所有条目，检查预览及放下后的 fallback。所有完成用例 `fallbackArtIds`、绘制错误、呈现错误均为空。

密集截图只隐藏 DebugSpawnPanel 的 CSS，保留 TEST FIELD 和无限资源 HUD；不冒充正常波次。运行中实体死亡可能降低敌人数，实际数量见报告。正常模式独立截图见 `browser-final/`。

视觉限制仍可见：720px 高度的双 Boss HUD 与底部建造栏压缩可见区域，部分世界内容会位于 UI 下方；Phase 3 提示条也可能覆盖拖动预览。相机统一变换及点选验证通过不代表这些 UI 遮挡已获最终视觉验收，交由 UI/主审评估。

**151 项已有测试通过，生产构建通过。** 生产 bundle 不包含 DEV 控制桥和只读检查器入口。3 秒真实 RAF 性能样本记录各尺寸/DPR 的 callback CPU 和帧间隔，仅为当前机器 headless Edge 的短时观测，不构成长时间性能、GPU 或其他硬件保证。
