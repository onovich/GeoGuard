# Boss 重设计执行文档

## 目标

这轮重设计不只是“给 Boss 多几个技能”，而是把 Boss 战从大号精英怪，升级成真正有记忆点、有策略应对、有舞台表现力的遭遇战。

核心目标有 5 个：

1. 每个 Boss 都要有清晰的战斗主题，玩家能快速理解“这一战在考什么”。
2. 每个 Boss 都要有至少一种强识别度的表现元素：轮廓、出招预兆、阶段转场、场地压制方式。
3. 每个 Boss 都要给玩家留出应对空间，而不是纯数值压人。
4. Boss 的阶段变化要改变战斗节奏，而不只是技能数量叠加。
5. 系统层要支持复杂遭遇，比如双体 Boss、联动机制、阶段转场演出、战后余波结算。

## 当前问题

### 结构问题

1. 现有系统默认一个波次只生成一个 Boss 实体，复杂遭遇会被强行压成“单体大怪”。
2. `TWINS` 目前只是一个双头造型，不是真正的双子遭遇，名称和体验不一致。
3. Boss 技能现在更像散装触发器，缺少“招式组”和“战斗意图”。
4. 阶段变化只是在血量阈值处追加技能，节奏变化还不够明显。

### 表现问题

1. Boss 进场有提示，但常驻表现还不够强。
2. 出招预兆已经有基础线/圈，但不同 Boss 的视觉语汇不够区分。
3. 阶段切换缺少足够明显的“转场感”和“战局改变感”。

### 策略问题

1. 部分 Boss 更像“持续放技能”，玩家很难形成稳定的识别和反制经验。
2. 有些 Boss 的压力主要来自频率，而不是模式组合。
3. 召唤、控场、位移、点杀之间还没有形成足够鲜明的职责分化。

## 设计原则

### 1. 先看懂，再压迫

Boss 可以强，但必须先可读。每类危险都要让玩家先识别，再移动，再失误。

### 2. 每个 Boss 只考 1 到 2 个核心能力

例如：

- 追击与换位
- 站位与走位
- 防线保护与补位
- 贪资源的代价
- 场地压缩下的路线选择

### 3. 阶段不是简单加法

阶段切换至少要满足下面一项：

- 改变空间关系
- 改变目标优先级
- 改变 Boss 的进攻节奏
- 改变玩家的应对策略

### 4. 表现服务于机制

表现不是额外装饰。造型、颜色、预兆、粒子、文本，都应该帮助玩家更快判断危险类型。

### 5. 复杂遭遇优先抽象成“遭遇”

后续系统不要只围绕单个 Boss 实体设计，而要支持：

- 单体 Boss
- 双体 Boss
- 主从 Boss
- 多阶段形态切换
- 战后余波结算

## Boss 系统改造范围

### A. 遭遇层

需要把 Boss 从“单个实体模板”升级为“Boss 遭遇模板”。

最低支持：

1. 单体遭遇
2. 双体遭遇
3. 共享进场提示
4. 共享战后结算
5. 成员间联动状态

### B. 表现层

需要补强：

1. 常驻 Boss 顶部信息区
2. 更清晰的阶段切换反馈
3. 更统一的预兆语汇
4. 双体 Boss 的身份区分
5. 招式释放时的短时演出强化

### C. 机制层

能力分成 6 类，后续所有 Boss 技能优先复用这些语汇：

1. 冲锋 / 突进
2. 直线压制 / 扫射
3. 区域封锁 / 陷阱
4. 召唤 / 场面经营
5. 牵引 / 击退 / 换位
6. 联动 / 节奏爆发

## 执行顺序

### 第一阶段：系统地基

1. 引入 Boss 遭遇抽象
2. 支持双体 Boss 的生成、联动、结算
3. 为召唤物和危险区补 encounter 归属
4. 梳理阶段切换和战后余波的统一规则

### 第二阶段：表现地基

1. 常驻 Boss HUD
2. 阶段转场表现
3. 预兆色彩和形状规范
4. 进场提示与双体标识

### 第三阶段：标杆 Boss

优先做 4 个最能拉高整体上限的 Boss：

1. Twins
2. Dragon
3. Spider Matriarch
4. Astrolabe

这 4 个完成后，剩余 Boss 可以沿着已经跑通的系统继续扩。

### 第四阶段：第一轮全集群重做

按照波次顺序，把前 8 个 Boss 全部重做一轮，确保真实关卡体验平顺。

### 第五阶段：后半区强化

重做后 8 个 Boss，并重新整理整套关卡曲线与高压段落。

## Twins 详细需求

### 战斗定位

`TWINS` 不再是一个双头怪，而是两个独立实体组成的一场遭遇。

### 成员分工

1. 日子体：更主动、更快、更偏直线压迫
2. 月子体：更控场、更慢、更偏限制走位

### 联动要求

1. 两个个体需要同时登场
2. 两个个体要共享进场提示
3. 至少有一个双人联动技能
4. 其中一个死亡后，另一个进入强化状态
5. 只有双子全部死亡且余波清空后，才进入 Boss 奖励

### 表现要求

1. 两体造型必须一眼可分
2. 颜色和危险语汇必须区分
3. 联动技能要让玩家感知“它们在一起作战”

## 验收标准

满足下面这些，才算这轮 Boss 重设计方向站住了：

1. 双子在视觉、机制、结算上都已经是真双子。
2. 玩家在第一次见到 Boss 时，能大致猜出危险类型。
3. 阶段切换能被感知到，而不是后台数值变化。
4. Boss 战结束后，节奏切换自然，不会被残留技能硬接下一波。
5. 系统已经能支撑后续继续做更复杂的 Boss。
